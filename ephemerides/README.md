# Эфемериды свободного полёта

`horizons.json` содержит геометрические координаты и скорости восьми планет относительно центра Солнца и Луны относительно центра Земли. Векторы заданы в эклиптике J2000. Положение измеряется в а.е., скорость в а.е. за сутки, даты в UTC. Координаты описывают один физический момент без поправки на время распространения света.

Сборка включает эту таблицу для мгновенного старта. Браузерная версия получает файл из ветки выпуска. Android дополнительно запрашивает у JPL более частую сетку, на 16 суток за раз. Все планеты переключаются на новую таблицу одновременно. Между отсчётами игра использует положения и скорости обоих концов интервала для кубической интерполяции. При недоступной сети за пределами сохранённой таблицы положение рассчитывает Astronomy Engine. У отдельных космических аппаратов остаются собственные каталожные координаты.

Чтобы подготовить новую таблицу на 512 суток с заданной даты UTC, выполни из корня проекта `node scripts/update-ephemeris.mjs 2026-10-01 512`. Скрипт делает девять последовательных запросов и заменяет файл только после проверки всех ответов. Начало, конец временного окна и момент получения записаны в самих данных.

- [NASA/JPL Horizons API](https://ssd-api.jpl.nasa.gov/doc/horizons.html)
- [Условия использования API JPL](https://ssd-api.jpl.nasa.gov/doc/index.php)
- [Astronomy Engine, Don Cross, лицензия MIT](https://github.com/cosinekitty/astronomy)
