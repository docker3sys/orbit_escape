## Следующий выпуск

В ветках с процессом «Archive tagged Android build» публикация тега вида `v1.4.0` запускает сборку. APK, AAB и контрольные суммы сохраняются в черновике [GitHub Releases](https://github.com/docker3sys/orbit_escape/releases). Исходники выпуска доступны там же. Бинарники собираются без издательского ключа. Для установки и публикации в RuStore используется отдельная подписанная копия.

Git хранит каждый отправленный коммит. Личные сохранения игры остаются на устройстве.
